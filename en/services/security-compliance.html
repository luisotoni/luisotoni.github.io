🔒 Security & Compliance

Data protection and regulatory compliance in Microsoft environments

About the Service

Complete protection for your Microsoft infrastructure with focus on Zero Trust, defense in depth and regulatory compliance. I implement security solutions that protect your data while enabling user productivity.

What's included:

  • Azure Security Center / Microsoft Defender for Cloud
  • Microsoft Sentinel (SIEM/SOAR)
  • Microsoft Defender suite (Endpoint, Identity, Office 365)
  • Conditional Access policies
  • Multi-Factor Authentication (MFA)
  • Data Loss Prevention (DLP)
  • Information Protection & Sensitivity Labels
  • LGPD/GDPR compliance
