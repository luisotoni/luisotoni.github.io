Automatizando Procesos con Power Automate

👤 Luís Otoni 📅 15 de Noviembre de 2025 ⏱️ 10 min de lectura 📁 Power Platform

Power Automate es la herramienta de automatización de Microsoft que permite crear workflows sin código (o con código mínimo) para automatizar procesos repetitivos. En esta guía práctica, mostraré cómo comenzar con automatizaciones y compartiré ejemplos reales de uso.

¿Qué es Power Automate?

Power Automate (anteriormente Microsoft Flow) es una plataforma de automatización que permite conectar aplicaciones y servicios para crear workflows automatizados. Piense en él como un "si esto, entonces aquello" a escala empresarial.

Tipos de Flows

  • Cloud Flows: Automatizaciones en la nube basadas en eventos
  • Desktop Flows (RPA): Automatización de tareas en desktop con UI automation
  • Business Process Flows: Guías visuales para procesos de negocio

Casos de Uso Comunes

Antes de sumergirnos en el "cómo", veamos algunos ejemplos prácticos donde Power Automate brilla:

1. Aprobaciones

  • Requisiciones de compra
  • Solicitudes de vacaciones
  • Aprobación de documentos
  • Liberación de presupuestos

2. Notificaciones

  • Alertas cuando se crea un nuevo elemento
  • Notificaciones de plazos próximos
  • Resúmenes diarios por email
  • Avisos de cambios en documentos importantes

3. Sincronización de Datos

  • SharePoint ↔ SQL Database
  • Excel ↔ Dataverse
  • Forms ↔ SharePoint Lists
  • Dynamics 365 ↔ Sistemas legados

Creando Su Primer Flow

Vamos a crear un flow simple pero útil: notificar al equipo en Teams cuando se agrega un nuevo archivo a una carpeta específica de SharePoint.

Paso 1: Acceda a Power Automate

Navegue a make.powerautomate.com e inicie sesión con su cuenta Microsoft 365.

Paso 2: Crear un Nuevo Flow

  1. Haga clic en "Create" en el menú lateral
  2. Seleccione "Automated cloud flow"
  3. Dé un nombre descriptivo: "Notificar equipo - nuevo archivo SharePoint"
  4. Busque y seleccione el trigger: "When a file is created (properties only)" de SharePoint

Paso 3: Configurar el Trigger

  • Site Address: Seleccione su sitio SharePoint
  • Library Name: Elija la biblioteca de documentos
  • Folder: Especifique la carpeta (o deje vacío para toda la biblioteca)

Paso 4: Agregar Acción

  1. Haga clic en "New step"
  2. Busque "Teams" y seleccione "Post message in a chat or channel"
  3. Configure:
    • Post as: Flow bot
    • Post in: Channel
    • Team: Seleccione su equipo
    • Channel: Elija el canal
    • Message: Use contenido dinámico

Ejemplo de mensaje:

📄 ¡Nuevo archivo en SharePoint!

Nombre: {Name}
Creado por: {Created By DisplayName}
Link: {Link to item}

Haga clic en el enlace para ver el archivo.

Paso 5: Probar y Guardar

  1. Haga clic en "Test" en la esquina superior derecha
  2. Seleccione "Manually"
  3. Suba un archivo de prueba a SharePoint
  4. Verifique si la notificación llegó a Teams
  5. Guarde el flow

Flows Avanzados: Aprobaciones

Ahora vamos a crear algo más robusto: un sistema de aprobación de gastos.

Escenario

Empleado completa Form → Gerente recibe solicitud de aprobación → Si se aprueba, datos van a SharePoint y email se envía a finanzas → Si se rechaza, solicitante recibe feedback.

Trigger

  • Connector: Microsoft Forms
  • Trigger: "When a new response is submitted"

Acciones

  1. Get response details (Forms)
    • Captura todas las respuestas del formulario
  2. Start and wait for an approval (Approvals)
    • Approval type: Approve/Reject - First to respond
    • Title: "Aprobación de Gasto - {Responder's Email}"
    • Assigned to: email del gerente
    • Details: Incluir valores del form
  3. Condition
    • If Outcome = Approve
  4. Yes branch:
    • Create item (SharePoint)
    • Send email (Office 365 Outlook) a finanzas
    • Send email al solicitante confirmando aprobación
  5. No branch:
    • Send email al solicitante con feedback del rechazo

Best Practices

1. Nomenclatura Clara

  • Use nombres descriptivos para flows
  • Renombre acciones para indicar propósito
  • Use prefijos para organización (ej: "FIN - Aprobación de Gasto")

2. Tratamiento de Errores

  • Configure "Configure run after" para capturar fallos
  • Agregue notificaciones de error
  • Use scope para agrupar acciones y facilitar error handling

3. Performance

  • Use polling triggers con cuidado (consumen ejecuciones)
  • Implemente "Do until" con timeout
  • Evite loops anidados cuando sea posible
  • Use "Apply to each" con parsimonia

4. Seguridad

  • Use connections compartidas con cuidado
  • Implemente DLP policies
  • No almacene credenciales en flows
  • Use service accounts para conexiones compartidas

5. Mantenibilidad

  • Documente flows complejos
  • Use variables para valores reutilizados
  • Modularice con child flows cuando sea apropiado
  • Mantenga flows simples - divida la complejidad

Desktop Flows (RPA)

Para automatizaciones que involucran aplicaciones desktop o sistemas legados sin APIs, use Desktop Flows.

Casos de Uso

  • Entrada de datos en sistemas legados
  • Extracción de datos de PDFs o pantallas
  • Automatización de tareas repetitivas en Windows
  • Integración con aplicaciones sin API

Cómo Comenzar

  1. Instale Power Automate Desktop (gratis con Windows 11)
  2. Grabe sus acciones usando el recorder
  3. Refine el script generado
  4. Pruebe en diferentes escenarios
  5. Publique y programe la ejecución

Conectores Populares

Power Automate tiene 400+ conectores. Aquí están los más usados:

Microsoft

  • SharePoint - Gestión de documentos y listas
  • Outlook - Email automation
  • Teams - Comunicación y colaboración
  • Planner - Gestión de tareas
  • Dataverse - Base de datos estructurada

Terceros

  • SQL Server - Database operations
  • Salesforce - CRM integration
  • Mailchimp - Email marketing
  • Twitter - Social media automation
  • Twilio - SMS automation

Gobernanza y CoE

En implementaciones enterprise, la gobernanza es crucial:

Center of Excellence (CoE) Kit

  • Instale el CoE Starter Kit gratuito de Microsoft
  • Monitoree uso y adopción
  • Identifique flows huérfanos o rotos
  • Establezca estándares y templates
  • Capacite makers

DLP Policies

  • Agrupe conectores por sensibilidad
  • Bloquee conexiones inapropiadas
  • Implemente aprobaciones para conectores premium

Conclusión

Power Automate es una herramienta poderosa que democratiza la automatización. Con ella, cualquier persona puede eliminar tareas repetitivas y enfocarse en lo que realmente importa.

Comience pequeño: automatice algo que hace todos los días. Aprenda de la experiencia y expanda gradualmente. Antes de darse cuenta, habrá ahorrado horas de trabajo manual cada semana.

Próximos pasos: Visite make.powerautomate.com y cree su primer flow hoy. Use los templates disponibles como punto de partida.
