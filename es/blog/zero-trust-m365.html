Microsoft 365 Zero Trust Seguridad

Implementando Zero Trust con Microsoft 365

👤 Luís Otoni 📅 5 de Noviembre de 2025 ⏱️ 15 min de lectura 📁 Seguridad

El modelo Zero Trust es un enfoque de seguridad que parte del principio "nunca confíe, siempre verifique". En un mundo donde el perímetro de seguridad tradicional ya no existe - con trabajo remoto, dispositivos personales y aplicaciones cloud - Zero Trust se ha vuelto esencial.

Los 3 Principios del Zero Trust

  • Verificar explícitamente: Siempre autentique y autorice basado en todos los datos disponibles
  • Usar acceso con privilegio mínimo: Limite el acceso del usuario con Just-In-Time y Just-Enough-Access
  • Asumir violación: Minimice el blast radius y segmente el acceso

1. Identidad: La Fundación del Zero Trust

En el modelo Zero Trust, la identidad es el nuevo perímetro. Comience fortaleciendo la autenticación.

Multi-Factor Authentication (MFA)

MFA es obligatorio. Microsoft Entra ID ofrece varias opciones:

  • Microsoft Authenticator: Push notifications, OTP, passwordless
  • FIDO2 Security Keys: Llaves físicas para máxima seguridad
  • Windows Hello: Biometría integrada a Windows

2. Conditional Access: El Cerebro del Zero Trust

Conditional Access es donde las decisiones de acceso ocurren en tiempo real, basado en múltiples señales.

Políticas Esenciales

  • Require MFA for All Users
  • Block Legacy Authentication
  • Require Compliant Device for Sensitive Apps
  • Risk-Based Conditional Access

Roadmap de Implementación

Fase 1: Quick Wins (Semanas 1-2)

  • ✅ Habilitar Security Defaults (si no tiene CA configurado)
  • ✅ Forzar MFA para todos los administradores
  • ✅ Bloquear autenticación legada
  • ✅ Crear break-glass accounts

Conclusión

Implementar Zero Trust es una jornada, no un proyecto único. Microsoft 365 ofrece todas las herramientas necesarias - Conditional Access, Identity Protection, Intune, Information Protection y Defender for Cloud Apps trabajan juntos para crear una arquitectura de seguridad robusta.
